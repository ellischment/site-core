# STATE

Только текущее состояние и открытые вопросы. История в коммитах.

## Сейчас

Этап 4 идёт: модуль requests готов. Дальше booking, catalog, blog, reviews, gallery.

Что есть:
- Next 16.3, React 19.2, Prisma 6.19 (SQLite, WAL), схема в `prisma/schema/` (ядро `core.prisma`).
- Вход, блокировка после 5 неудач на час, сессии в базе, роли owner/admin/tech.
- Админка: реестр разделов `lib/admin-sections.ts`, «Обзор», «Доступы», «Журнал действий», «Система», смена пароля, настоящий 403.
- `lib/action.ts` (panelAction), `lib/cache.ts` (карта сброса ядра + модулей), `lib/audit.ts`, `lib/crypto.ts`, `lib/time.ts` (зона из конфига).
- `proxy.ts`: закрытие /admin, отдельный домен админки из конфига, 404 для выключенных модулей (`lib/routing.ts`).
- `/api/cron`: задачи ядра и модулей по ключу.
- Модули: реестр `modules/registry.ts`, описание `modules/types.ts`. Схема модуля в `modules/<id>/schema.prisma`, копия в `prisma/schema/module-<id>.prisma` (`npm run db:schemas`, тест на расхождение).
- Модуль **requests**: форма (каналы из конфига, контакт по каналу: телефон, Telegram, почта), конвейер (частота 5/10 мин, дубли 10 мин, шифрование, запись до уведомления), уведомление в Telegram без ПДн с повторами 1/5/15/60 мин, раздел «Заявки» (статусы, удаление, тест уведомления), уборка IP через час и заявок через keepDays.
- SQLite: одно соединение на процесс (`lib/db.ts`), иначе всплеск записей давал Socket timeout.
- `npm run check`: миграции, типы, линтер, юнит-тесты, сборка, сквозные тесты.
- `client.config.ts` + схема `lib/config-schema.ts`: название, реквизиты, контакты, точки, домены (в т.ч. отдельный домен админки), модули, меню, SEO, интеграции. Проверяется при импорте.
- `theme/tokens.ts`: цвета светлой и тёмной схем, радиусы, тени, отступы, размеры, шрифты по ролям. CSS-переменные собирает `lib/theme.ts`.
- Шрифты своими файлами: `npm run fonts:add -- <шрифт> --weights 400,600 [--italic]` берёт @fontsource через npm, генерирует `theme/fonts.ts` (next/font/local, поднабор = своё семейство с unicode-range).
- Переключатель схемы `components/ThemeToggle.tsx`, раздел «Внешний вид», `/styleguide` (в проде только после входа).
- Тесты: `tests/no-client-values.test.ts` (нет сырых цветов и значений клиента в app/components/modules, кусается), `theme/theme.test.ts` (контраст обеих схем).
